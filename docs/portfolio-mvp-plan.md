# Portfolio Website MVP Plan

## Objective
Build a dynamic personal portfolio website for Yuval Digmal that presents CV content in a high-credibility format and can expand to include work samples and demos.

## Target Outcome
Increase qualified inbound interview conversations for:
- Senior Operations Engineer
- Product Support Engineer (Enterprise)
- Product Owner (Technical / Integrations)
- Implementation Manager / Technical Implementation Lead

## Audience
- Recruiters and talent teams (fast scan behavior)
- Hiring managers (evidence-driven technical credibility)
- Product/Engineering leaders in B2B SaaS

## Core Messaging
"Technical Product Operations leader bridging Product, Engineering, and Enterprise customers to deliver scalable integrations, resolve complex production challenges, and drive measurable operational impact."

## MVP Scope (Phase 1)
- One-page site with anchored sections
- Dynamic content source (JSON/MD) for easy updates without code changes
- Sections:
  - Hero
  - Impact Highlights
  - Experience Timeline
  - Skills Matrix
  - Case Studies (3 initial)
  - Contact CTA
- Primary CTA: Send email / Book conversation
- Secondary CTA: Download CV
- Tertiary CTA: LinkedIn

## Phase 2 (Future)
- Dedicated Portfolio page
- Demo gallery (Loom, architecture diagrams, code snippets)
- Optional contact form and analytics dashboard

## Success Metrics
- North Star: Qualified Contact Rate
- Supporting KPIs:
  - CV Download CTR
  - Case Study Click Rate
  - Contact CTA Click Rate
- Baseline: unknown (collect after launch)

## Risks and Mitigation
- Missing quantified outcomes
  - Mitigation: replace generic bullets with measurable impact metrics
- Missing public links (LinkedIn/CV)
  - Mitigation: add placeholders now, replace before launch
- Over-scoping visual design
  - Mitigation: freeze MVP IA and CTA priorities

## Launch Checklist
- Content finalized and proofread
- LinkedIn and CV links added
- Mobile and desktop QA
- Lighthouse baseline check
- Deploy and validate CTA links
